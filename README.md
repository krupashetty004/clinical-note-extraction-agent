# AI-Powered Clinical Note Extraction and Coding Agent (MVP)

## Current Status

**Phase:** Planning and research only.

> **Hard rule:** No feature implementation may begin until Mirai Labs provides formal architecture and technology-stack approval (scheduled 16 Oct 2026).

This private repository is organized to support Mirai Labs intern-evaluation planning deliverables for a documentation-first MVP proposal.

## Project Objective

Design an MVP for structured extraction from free-text clinical notes with:
- evidence-backed entities (diagnoses, procedures, medications, allergies, vitals),
- source-text span traceability (character offsets),
- independent verification,
- ICD-10 candidate support with abstention,
- reviewer oversight and export,
- measurable evaluation against a labelled gold standard.
